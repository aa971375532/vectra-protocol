# Security Policy

## 🔒 Responsible Disclosure

Vectra Protocol Foundation places top priority on the security of our smart contracts, Token-2022 configurations, and client SDKs.

If you believe you have discovered a vulnerability in Vectra:

1. **Do NOT** open a public issue on GitHub.
2. Email full technical details and reproduction steps to: `security@vectra.network` (or contact the core developers via private encrypted channels).
3. We endeavor to respond to all valid vulnerability reports within 24 hours.

---

## 🛡️ Bug Bounty Scope

- Token-2022 TransferFeeConfig authorization bypasses.
- Re-entrancy, arithmetic overflow, or logic flaws in payment escrow contracts.
- Signature forgery in the HTTP 402 middleware.
